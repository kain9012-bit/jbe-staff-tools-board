# 게시글 요약 작성 지침

「교직원 제작 도구 현황」 도구 상세 화면의 **한눈에 보기**에 들어가는 요약을 쓰는 기준.
새 게시글이 올라올 때마다 이 지침 그대로 작성해 구조와 말투를 맞춤.

## 1. 원칙

- **본문 비게재:** 원 게시글 본문은 화면에 싣지 않음. 정해진 항목으로 짧게 정리한 요약만 게재
- **원문 근거:** 게시글 본문·첨부파일 이름·링크에 있는 내용만 사용. 추측·보충 금지
- **짧고 간결:** 항목마다 한 줄. 길면 줄여서 다시 씀
- **명사형 끝맺음:** "~함", "~합니다" 대신 명사로 끝냄 (예: "자동 계산", "일괄 생성")
- **빼는 것:** 홍보 문구, 이모지, 감탄, 비밀번호·암호키, 전화번호·메신저 아이디 등 연락처, 사람 이름
- **원문 문장 복사 금지:** 원문 문장을 그대로 옮기지 않고 짧게 다시 씀

## 2. 항목

| 항목 | 키 | 필수 | 기준 |
|---|---|---|---|
| 한 줄 소개 | `what` | 필수 | 무엇을 해 주는 도구인지. 40자 이내. 업무 대상 + 하는 일 |
| 주요 기능 | `features` | 필수 | 1~3개. 각 30자 이내. 사용자가 실제로 얻는 결과 위주 |
| 실행 방식 | `run` | 필수 | 아래 8가지 중 하나만 |
| 필요한 것 | `needs` | 선택 | 계정·API 키·브라우저·원자료·암호 확인 등. 한 줄 |
| 유의사항 | `caution` | 선택 | 대상 한정, 시험판, 데이터 삭제 위험, 외부 링크 내려받기 등. 한 줄 |
| 설명 부족 | `thin` | 선택 | 게시글 설명이 몇 줄뿐이라 확인된 내용만 적었을 때 `true` |
| 설명 없음 | `empty` | 선택 | 본문이 비어 요약할 내용이 없을 때 `true` (다른 항목 생략) |
| 정리한 날 | `at` | 필수 | `YYYY-MM-DD` |

### 실행 방식 8가지 (`run`)

| 값 | 판단 기준 |
|---|---|
| 웹 접속 | 주소로 접속해 바로 쓰는 사이트 |
| HTML 파일 | 내려받은 .html 파일을 브라우저로 여는 방식 |
| 브라우저 확장 | 크롬·엣지 확장 프로그램 (개발자 모드 로드 포함) |
| 설치 프로그램 | .exe 등 PC에서 실행하는 프로그램 (설치 없는 실행 파일 포함) |
| 북마크 | 북마크바에 끌어다 놓고 누르는 방식 |
| 구글 시트 | 구글 시트 사본·앱스 스크립트 기반 |
| AI 챗봇 | 커스텀 GPT, 노트북LM 등 대화형 AI |
| 기타 | 위에 해당하지 않거나 게시글로 판단 불가 |

판단이 둘 이상이면 사용자가 **처음 여는 방식**을 고름. 예: 웹 사이트지만 설치 파일을 받아야 쓰면 `설치 프로그램`.

### 자주 쓰는 표현

- 필요한 것: `크롬·엣지`, `구글 로그인`, `ChatGPT 계정(커스텀 GPT)`, `Gemini API 키`, `블로그에서 1일 암호 확인`, `나이스 명단 엑셀`
- 유의사항: `테스트 버전`, `시험판`, `전북 에듀파인 전용`, `입력 내용은 브라우저에만 저장`, `파일이 커서 외부 링크로 내려받기`

## 3. 예시

```json
"1175824": {
  "what": "K-에듀파인 원인행위 본문 정형 양식 자동 작성",
  "features": ["관련 문서번호 자동 검색 입력", "품명·금액·거래처 자동 작성", "업무추진비 협의회 양식"],
  "run": "브라우저 확장",
  "needs": "크롬",
  "caution": "물품·용역·업무추진비만 대상, 건명은 직접 작성, 전북 에듀파인 전용",
  "at": "2026-10-09"
}
```

설명이 짧은 글:

```json
"1169995": {
  "what": "현금출납부와 농협은행 거래 금액 대조",
  "features": ["잘못된 금액을 시간별로 표시"],
  "run": "설치 프로그램",
  "needs": "블로그에서 1일 암호 확인",
  "thin": true,
  "at": "2026-10-09"
}
```

## 4. 새 게시글 요약 절차

1. **새 글 찾기:** 사용자 PC에서 `python tools/fetch_new_posts.py` 실행. 도구목록 시트의 '게시중' 글 가운데 `src/data/summaries.json`에 없는 글만 본문을 읽어 `_probe/sum/new_posts.json`으로 저장
2. **요약 작성:** 이 지침 2·3장 기준으로 글마다 작성
3. **저장:** `src/data/summaries.json`의 `items`에 `dataSid`를 키로 추가. 기존 항목은 고치지 않음
4. **배포:** 깃허브에 올리면 Vercel이 다시 빌드해 화면에 반영

요약이 없는 글은 상세 화면에 "아직 게시글 요약이 없습니다."와 원 게시글 링크가 표시됨.
게시글이 크게 고쳐진 경우에만 해당 항목을 다시 쓰고 `at`을 새 날짜로 바꿈.
